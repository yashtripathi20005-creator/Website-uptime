# Website Uptime Checker

A comprehensive web application for monitoring website availability and performance.

## Features

- **Real-time Monitoring**: Continuously checks websites every 60 seconds
- **Status Dashboard**: View all monitored sites with their current status
- **Performance Metrics**: Track response times and status codes
- **Uptime Percentage**: Calculate uptime percentage for the last 24 hours
- **History View**: See detailed history of checks for each site
- **Beautiful UI**: Clean, responsive design with modern styling
- **Add/Remove Sites**: Easily manage monitored websites
